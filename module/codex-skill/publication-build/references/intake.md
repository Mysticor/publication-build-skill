checksums/readiness. Support equivalent file names by a documented local alias map without
changing Stage 3. Required canonical: reviewed_manuscript.md; references.bib if citations.

actually citation-free equivalent handoff before freeze). Archive original handoff untouched.

carry harmless documented items, block issues affecting submission/content validity.
