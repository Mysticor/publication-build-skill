# Generic builds

Without a target journal, declare GENERIC_ACADEMIC_BUILD. Respect any user template; otherwise choose a suitable article/report layout from the request. The bundled academic-paper.tex is an optional starting point selected explicitly by `template --kind generic`. It is not a page target or a guarantee of arXiv acceptance. For another generic layout use `template --kind user --path PATH`. Replace sample metadata and content; preserve real content. Generic readiness never means journal submission readiness. A later journal change starts a new build.
