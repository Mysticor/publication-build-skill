# Decision Policy

Automatic: compiler passes, package-compatible fixes, floats within official style,
figure physical sizing, required export format/resolution, safe crop, ordinary legend corner.
Consequential: uploaded old template vs currently mandatory new one; real target-journal
conflict; unresolved anonymous/full scope; multiple compliant visual solutions changing panel
hierarchy/color meaning; content limits requiring scientific edits; unknown author declarations.
Only ask for the missing decision, explain actual evidence, record alternatives/status/outcome
in author_decisions. Gate A template/target, B material compliance, C anonymity, D final freeze
are conditional, never ritual approval. No meaningful choice → continue to final checks.
Use statuses AUTHOR_INPUT_REQUIRED for missing facts, CONTENT_REVISION_REQUIRED for scientific
changes, TEMPLATE_REQUIRED for required template; preserve pending decisions on resume.
