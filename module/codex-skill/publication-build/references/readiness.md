# Readiness

Build states: BUILD_IN_PROGRESS, TEMPLATE_REQUIRED, AUTHOR_INPUT_REQUIRED,
CONTENT_REVISION_REQUIRED, BUILD_FAILED, PUBLICATION_READY_WITH_MINOR_ISSUES,
PUBLICATION_PACKAGE_READY, BLOCKED. Successful generic/test builds use separate markers.
All ten audits journal/mapping/figures/tables/references/supplementary/anonymity/content/visual/
submission must have actual evidence and current fingerprint. Use justified N/A observations
within PASS audit when not applicable. No blank/global PASS reports. All builds, frozen content,
profile, official core, PDF pages, required assets and clean ZIP must be current. No blockers or
pending consequential choices. Minor issues must be documented, rule-compliant and user-visible;
never silently treat a required missing item as minor. Refresh invalidated audits after changes.
Helper finalize verifies evidence fingerprints and writes marker, not an approval request.
Report source/PDF/ZIP paths, engine/template/official date, QA outcomes and real limitations.
No claims of a real journal acceptance, automatic submission, or universal publisher support.
