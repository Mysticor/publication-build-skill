# Pdf Qa

Render and open every page of every final main/SI/required variant PDF at legible scale.
Check title/authors/affiliations/abstract, columns, headings, paragraph flow, page breaks,
equations, figures/labels/captions, tables/notes, references, SI, headers and page/line numbers.
Look for clipping, huge blank regions, floats too far from discussion, unreadable graphics,
overflow, orphan headings, font substitution and broken characters. Render existence is not
visual inspection. Fix allowed layout → rebuild → re-render → reinspect affected full output.
For the visual audit report record reviewer, observations and inspected_pages mapping each
PDF path to every preview filename listed in state.builds. Attest only after actual image viewing.
Clear warnings may be reported as minor only if they violate no submission rule or integrity.
