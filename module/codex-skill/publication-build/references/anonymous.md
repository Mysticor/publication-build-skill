title page does not imply another full manuscript PDF. If rules resolve it, proceed automatically.

identity fields in generated variants. Check names, affiliations, acknowledgments, funding,
repository links, identifying prose, PDF metadata and supplementary metadata. `anonymous`
helper searches known identity strings in text/PDF info, but manual indirect-identity review
is still required. Removing scientifically material identifying detail needs author/Stage3
routing, not silent scientific redaction. Never claim complete anonymity from a name scan alone.
