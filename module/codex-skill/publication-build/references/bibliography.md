# Bibliography

Check citation keys in canonical main text, captions and SI ↔ BibTeX entries ↔ compiled
.bbl ↔ rendered bibliography, accounting for the template's shared or separate lists.
Resolve missing/duplicate keys, invalid entries, required unused-entry handling, wrong style
and unresolved references. Reuse strict compilation rather than inventing a new parser.
Compare the reviewed source's actual cited works with the rendered main/SI set; renumbering
or repeat appearances across lists do not create new works. Preserve legitimate citations
when resolving duplicate keys/records. Do not add uncited entries or use nocite{*} to reach
an inherited target, drop citations to fit page counts, or double the target again.
If a verified journal reference limit conflicts with the reviewed manuscript, record the
conflict for a scoped Stage 3 content decision (or the author for standalone typesetting)
before cutting references; Stage 4 does not choose scientific additions/removals.
Metadata questions may use available nature-ref-verifier, narrowly scoped to known entries;
no broad literature search, scientific reviewer, or fabricated DOI/author/date.
Verify crossrefs show real values, not ??; duplicate labels and rerun warnings need resolution.
