# Third-party executor

The bundled academic-typesetting executor derives from https://github.com/ndpvt-web/latex-document-skill. Its upstream README declares MIT (verified against main commit 47f72803a1cf8327186f8568441e8e9b71d2d205); the upstream does not supply a separate LICENSE file. The retained executor README includes the original license statement and attribution. This is a locally adapted snapshot, not a claim of byte identity to that commit.

Adaptations include strict compilation/error checks, dependency-install consent, publication orchestration, portable environment instructions and removal of a personal template default. Original upstream samples and contributor notices remain attributed.
